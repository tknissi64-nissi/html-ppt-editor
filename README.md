# HTML PPT Editor · 使用文档

给 **HTML 演示文稿**做的可视化编辑器。界面与操作习惯对标 Microsoft PowerPoint。

整个工具就是**一个 HTML 文件**。不需要安装、不需要联网、不需要服务器，
拷进 U 盘、发微信、丢邮件附件都能直接用。
---
因为存在需求，所以提供供给；

Vibe Coding了一个小项目：

解决html格式的演示文稿在修改和编辑的最后一公里；

内嵌了一套标准化模板，但我觉得真的不会有人用这玩意来从0写演示文稿

目前处于测试阶段，只能说bug随处可见

## 一、打开

**双击 `html-ppt-editor.html`**，建议用 **Chrome 或 Edge**。

> **为什么建议 Chrome / Edge**：这两个浏览器支持「原地保存」——`Ctrl+S` 会弹出真正的
> 文件保存对话框并覆盖同一个文件。其它浏览器只能"下载一份"，第二次保存会变成
> `xxx (1).html`，需要自己整理。

打开后是欢迎页，点「新建空白演示文稿」即可开始。

## 三、快速上手

### 1 · 新建

点「新建空白演示文稿」，直接得到 **封面 + 目录 + 一页正文**，已套好默认模板，
不是三张白纸。

### 2 · 加一页

**开始 → 新建幻灯片**（`Ctrl+M`）→ 弹出版式库，**16 个成套版式**带缩略预览，点哪个加哪个：

> 封面 · 一句话主张 · 目录 · 章节过渡 · 标题与要点 · 画面与说明 · 暗场画面 · 双联瓦片 ·
> 关键数字 · 单一数字 · 两栏对照 · 时间线 · 三图并置 · 引言 · 结尾 · 空白

想给**已有的页**换版式：**开始 → 版式**（会替换该页对象，有二次确认）。

### 3 · 改文字

**双击**任何文字直接改，改完点空白处或按 `Esc` 退出。

选中文本框后，「开始」选项卡里的字体、字号、加粗、对齐、行距、项目符号全部可用。
**选中其中一段文字再改格式，只作用于选中的那几个字**（加粗、字号、颜色、上标下标均可）。

### 4 · 加对象

| 要加什么 | 怎么做                                                       |
| -------- | ------------------------------------------------------------ |
| 形状     | 插入 → 形状 → 选一个 → **在画布上拖出大小**（直接单击则用默认尺寸） |
| 文本框   | 插入 → 文本框 → 拖出范围                                     |
| 图片     | 插入 → 图片，或**直接把图片文件拖进窗口**                    |
| 表格     | 插入 → 表格 → **拖过网格选行列数**                           |
| 图表     | 插入 → 图表 → 选类型                                         |
| 图标     | 插入 → 图标 → 搜关键词（如「增长」「客户」「风险」）         |
| 艺术字   | 先选中一个文本框 → 插入 → 艺术字 → 选效果                    |

### 5 · 摆位置

- **拖动**移动，**八个控制柄**缩放，**顶部圆柄**旋转，**黄色菱形柄**调形状（圆角、箭头颈宽等）
- 拖动时按 `Shift` 锁水平/垂直；缩放时按 `Shift` 锁比例、`Alt` 从中心缩放；旋转时按 `Shift` 每 15° 吸附
- 靠近其它对象或页面中线会自动出**红色参考线**并吸附
- 多选后用 **开始 → 排列** 里的对齐与分布
- 方向键微移 8px，`Ctrl+方向键` 或 `Alt+方向键` 精确移 1px

### 6 · 表格与图表

**表格**：单击一格 = 选中该格（右侧窗格显示"当前单元格"）；**双击**进入编辑；
`Tab` 跳下一格，在最后一格按 `Tab` 会自动加一行。
选中表格后功能区会多出「**表格设计**」和「**布局**」两个选项卡（样式库、行列增删、合并拆分）。

**图表**：**双击图表**弹出数据编辑器（第一列是类别，其余每列一个系列，可加行加列）。
选中图表后功能区会多出「**图表设计**」选项卡，可改类型、开关图例/网格/数据标签、改系列配色。

### 7 · 换配色

**设计 → 主题**，7 套预设一键切换；或 **设计 → 编辑主题令牌**逐个改。

关键在于：模板和所有默认对象的颜色都是**主题引用**而不是写死的色值。
改一个主色，封面、卡片、图表、表格、图标**全部跟着变**。

### 8 · 分节

**开始 → 节 → 新增节**，从当前页往下算一节。
缩略图窗格会出现节标题行，点一下折叠/展开，右键可重命名、整节上下移、删节。

### 9 · 出错了不要慌

- `Ctrl+Z` / `Ctrl+Y` 撤销重做
- 每 20 秒自动存一次草稿，意外关闭后下次打开会询问是否恢复
- **文件 → 从自动保存恢复**可以翻最近 8 份草稿

## 四、保存、导出与放映

| 操作            | 快捷键         | 说明                                                         |
| --------------- | -------------- | ------------------------------------------------------------ |
| 保存            | `Ctrl+S`       | Chrome / Edge 下原地覆盖原文件                               |
| 另存为          | `Ctrl+Shift+S` |                                                              |
| 打开            | `Ctrl+O`       | 也可以**把 .html 文件拖进窗口**                              |
| 从头放映        | `F5`           |                                                              |
| 从当前页放映    | `Shift+F5`     |                                                              |
| 打印 / 导出 PDF | `Ctrl+P`       | 新窗口排好版后按 `Ctrl+P`，目标选「另存为 PDF」，**边距设为无、勾选背景图形** |

**导出的 HTML 本身就是可以直接演的演示文稿。** 发给别人，对方双击就能放映，
不需要这个编辑器。文件末尾会内嵌一段工程数据，用本工具再打开可以无损续编；
不想带的话选「导出（不含工程数据）」。

### 放映时的按键

| 键                       | 作用         | 键    | 作用                |
| ------------------------ | ------------ | ----- | ------------------- |
| `← →` `空格` `PgUp/PgDn` | 翻页         | `F`   | 全屏                |
| `Home` `End`             | 首页 / 末页  | `N`   | 备注抽屉            |
| `O`                      | 幻灯片总览   | `S`   | 演讲者视图          |
| `B` / `W`                | 黑屏 / 白屏  | `G`   | 跳转到指定页        |
| `H`                      | 显示按键提示 | `Esc` | 关闭浮层 / 退出放映 |

**演讲者视图**：当前页 + 下一页预览 + 逐字稿 + 计时器，与观众窗口实时同步。
在编辑器内嵌放映里子窗口会被浏览器限制，需要在放映条上**右键 → 新窗口打开**，
或者直接放映导出后的文件。

## 六、两种页面模式

这是本工具唯一需要理解的概念。状态栏中间会显示当前页属于哪一种。

**自由画布页** —— 新建的页都是这种。绝对定位，跟 PowerPoint 一样随手拖摆，
放映时整页等比缩放。

**流式组件页** —— **打开别人做的 HTML 演示文稿**时，每一页都是这种。
它保留原文件的响应式排版，笔记本 / 大屏 / 会议室投影仪共用一份排版，永不越界。

- 直接点文字就能改，改完照样导出
- 想在上面加箭头、标注、遮罩：状态栏点一下切到「**自由对象**」，
  新加的对象会**浮在原组件之上**，原有的响应式排版完全不受影响

### 打开别人的文件时的保真承诺

- 原文件的样式表、脚本、页面骨架**原样保留**，一个字节都不改写
- 改主题只在末尾追加覆盖块，不动原文件里的品牌色声明
- 反复「打开 → 保存」**体积不膨胀、内容不漂移**
